## 📌 주요 문제 해결 영역

| 문제 유형 | 접근 기법 및 해결 방식 |
| --- | --- |
| **격자 시뮬레이션 및 완전 탐색** | 2차원 배열 회전, 중력 연산, dx/dy 테크닉을 활용한 복합 조건 구현 |
| **백트래킹 및 DFS / BFS** | 상태 공간 탐색, 가지치기, 최단 경로 및 영역 분할 탐색 |
| **동적 계획법** | 부분 성공 상태 정의, 메모이제이션을 활용한 최적 부분 구조 계산 |
| **자료구조 응용** | 우선순위 큐, 해시 맵, 셋을 활용한 탐색 시간 복잡도 개선 |
